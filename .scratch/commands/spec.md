# Спецификация: команды и доработка Трекеров задач и заметок

Термины — в `GLOSSARY.md` (Команда, Панель команд, Пользовательская команда, Расписание, Группа заметок, Активные/Завершённые заметки). Решение — `docs/adr/0004-commands-in-manifest-with-client-code.md`. Источник функций — описание десктопного трекера Iris (`Iris.Data.ProjectManagment.TaskTracker`).

## Цель

1. Заменить вкладку «Автоматизация» панелью «Команды»: команды подключённых расширений, сгруппированные по расширениям.
2. Дореализовать функции Iris, которых нет: расписание, отчёт, «Отложить» для категории, структура заметок «Активные/Завершённые».
3. Быстрый доступ к заметкам — команды, создаваемые и удаляемые действиями на заметке и группе заметок.

## Решения

- **Действие vs команда.** Действие работает с выбранным объектом (контекстное меню, таблица свойств). Команда глобальна и живёт на панели «Команды».
- **Действия (в типах):** Трекер задач — «Создать задачу» (корень, месяц, день, категория), «Завершить», «Отложить» (задача и новое — категория), ссылки. Трекер заметок — «Создать заметку/группу», «Завершить» (новое), ссылка, «Создать/Удалить команду для быстрого доступа» (заметка и группа).
- **Команды:** Трекер задач — «Создать расписание», «Выделить текущий день», «Отчёт по завершённым задачам». Трекер заметок — пользовательские команды быстрого доступа.
- **Команда в манифесте** (`commands` на уровне расширения: `id`, `name`, `description?`, `icon`, `parameters?` в формате параметров действий, `template?`). Код — `data.registerCommand(id, handler, { available })` на клиенте. Сервер валидирует и отдаёт команды с каталогом расширений.
- **Пользовательская команда** — скрытый платформенный тип: `name`, `extension`, `command`, `params`. Команда-шаблон (`template`) на панели не показывается, запускается только сохранённым экземпляром. Хуки расширения держат экземпляры в согласии с целями (переименование, удаление).
- **Панель.** Вкладка `commands`, пункт «Вид → Команды»; блок на каждое подключённое расширение (значок, название из каталога); расширения без доступных команд скрыты; пустое состояние «Нет доступных команд»; ошибка запуска — вверху панели; диалог параметров общий с действиями.
- **Отмена:** «Механизм», флаг типа `automation`, место показа `automation`, `SelectTodayMechanism`, `QuickAccessEntry`, `status` заметки (с приставкой в имени и цветовым правилом).
- **Заметки.** `NotesRoot` содержит `ActiveNotesRoot` и `CompletedNotesRoot` (singleton). Создавать можно только в активных. «Завершить» переносит заметку в завершённые в цепочку групп с теми же названиями (поиск по названию, недостающие создаются); пустую группу в активных не удаляем; возврата нет (Undo или перетаскивание).
- **Расписание.** Параметры «Начало» (по умолчанию сегодня) и «Конец» (по умолчанию конец года); начало ≤ конец, не более 365 дней; месяцы и дни только в «Текущих задачах», сб/вс — `DayOff`; идемпотентно; дни по требованию остаются. Горизонт повторов = max(конец следующего месяца, последний существующий день).
- **Отчёт.** Команда с «Начало» и «Конец»; `.xlsx` формируется в браузере лёгкой библиотекой только для записи; лист «Отчет», заголовок «Завершенные задачи за период ДД.ММ.ГГГГ – ДД.ММ.ГГГГ», колонки «Дата» и «Задачи» (через перенос строки, по названию), даты по возрастанию.
- **Чистка без миграции.** Данные тестовые; версии манифестов повышаются, БД пересоздаётся один раз (лоадер удалённые типы не убирает).

## Вне плана

Конструктор расширений (правка команд пользователем), серверный запуск команд, возврат заметки из завершённых отдельным действием.
