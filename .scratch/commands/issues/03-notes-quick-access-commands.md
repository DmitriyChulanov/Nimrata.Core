# 03: Быстрый доступ как пользовательские команды

**What to build:** Действия «Создать команду для быстрого доступа» и «Удалить команду для быстрого доступа» на заметке и группе создают и удаляют команду с именем цели.

**Blocked by:** 01, 02

**Status:** resolved

- [x] Команда-шаблон «Открыть в дереве» (`template`, параметр-ссылка `target`) выделяет цель в дереве
- [x] Действия на `Note` и `NoteGroup` создают и удаляют пользовательскую команду; повторное создание дубля не даёт; `available` по наличию команды
- [x] Хуки: переименование цели обновляет `name`, удаление цели с поддеревом удаляет команды
- [x] Удалены `QuickAccessEntry` и его код; команды быстрого доступа видны в блоке «Трекер заметок», отсортированы по названию
- [x] Тесты логики и панели
- [x] Запись в `CHANGELOG.md` клиента

## Answer

- Команда-шаблон `openInTree` выделяет цель в дереве; пользовательская команда — `CustomCommand` с `params.target`.
- Действия на `Note` и `NoteGroup` — `createQuickAccessCommand` / `removeQuickAccessCommand` (дубли не создаются, `available` по наличию команды).
- Хуки: переименование цели обновляет `name`, удаление цели с поддеревом удаляет команды. `QuickAccessEntry` удалён.
- Не проверено: визуально в светлой и тёмной темах.
