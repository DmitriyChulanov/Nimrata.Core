# 03: SyncEngine — пакетная отправка

**What to build:** Отдельный модуль сетевой части берёт наборы из очереди и отправляет их пакетами с окном 200 мс, по одному запросу одновременно, с лимитом операций.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Модуль `SyncEngine` в `src/platform/` (сеть отдельно от хранилища); константы: окно 200 мс, лимит 500 операций
- [ ] Окно отсчитывается от первой правки (не debounce); не больше одного запроса в полёте; новые наборы копятся
- [ ] Деление пакета по лимиту операций без разрыва набора; наборы не схлопываются
- [ ] Обработка ответа по статусам (`applied`, `duplicate`, `rejected`) → хранилище; при сетевой ошибке — повтор с экспоненциальной задержкой, очередь сохраняется
- [ ] Тесты на фейковых таймерах: тысяча правок за окно — один запрос; порядок; повтор после ошибки; `npm test`, `npm run lint`; `CHANGELOG.md` клиента
