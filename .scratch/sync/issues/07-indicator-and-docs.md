## Comments

- Индикатор — `platform/sync/SyncIndicator.tsx`: кнопка UI-кита (`Button ghost`) с иконкой реестра (`cloud-check`, `cloud-arrow-up`, `cloud-slash`, `cloud-warning`) и подписью; подсказка — свой `role="tooltip"` (виден при наведении и `:focus-within`, связан `aria-describedby`), отдельного компонента подсказки в UI-ките нет. Нажатие — «синхронизировать сейчас» (`kick` + `catchUp`). Вид и подписи — чистая `describeSyncStatus` (приоритет: офлайн → ошибка → неотправленные → синхронизировано).
- Состояние — контекст `SyncStatusProvider` (в шапке `App`): `DataController.getSyncState/subscribeSyncState` (SyncEngine: `SyncLink.getState/subscribeState`, `online | offline | error`), неотправленные всех вкладок `OfflineSync.unsentCount()` (пересчёт по очереди, состоянию связи, раз в 5 с и через 500 мс после смены очереди), ошибка загрузки, `AuthStatus 'offline'`.
- `offline`: сетевой сбой запроса (не `ApiError`) или обрыв открытого push-соединения (`PushHandlers.disconnected` — `onreconnecting`/`onclose`). Неудачный запуск SignalR не считается: SignalR оборачивает ответ сервера при negotiate в обычную ошибку и не отличает его от отсутствия сети.
- Открытое из 04 закрыто: `SyncLink.onResync`/`DataController.onResync` (push `resync` или ответ догона) → `extensionLifecycle` перечитывает каталог, приводит регистрации, запускает новые подключённые расширения, сбрасывает выделение недоступных.
- UI проверен в браузере на запущенном сервере worktree: индикатор с SignalR — «Синхронизировано»; контраст по вычисленным токенам в обеих темах ≥ 4,5:1 (приглушённый текст 4,51 на `--bg-hover` в светлой), значок ошибки ≥ 4,3:1; подсказка показывается на фокусе. Кольцо фокуса — общее правило `:focus-visible` из `base.css` (программный фокус в фоновой панели его не включил, клавишами проверить не удалось — панель не рисовалась).
