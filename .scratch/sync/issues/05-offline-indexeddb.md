# 05: Офлайн — снимок и очереди в IndexedDB

**What to build:** Снимок данных, курсор и очереди вкладок хранятся в IndexedDB. Правки переживают перезагрузку и отсутствие сети, очереди закрытых вкладок подхватываются.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] Тонкая обёртка над IndexedDB; база по `userId`: снимок объектов и типов, курсор, очереди по `tabId`
- [ ] Снимок пишется, только если `seq` больше сохранённого
- [ ] Старт: показать снимок из кэша, затем догон; без сети — работа на кэше
- [ ] Web Locks: lock вкладки; очередь вкладки с отпущенным lock подхватывается
- [ ] Logout: предупреждение при непустой очереди, затем удаление базы. Если вход истёк в офлайне — работа локально, после входа тем же пользователем очередь отправляется
- [ ] Тесты с `fake-indexeddb`; `npm test`, `npm run lint`; `CHANGELOG.md` клиента
