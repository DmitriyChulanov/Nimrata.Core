# 12: Undo/Redo

**What to build:** Пользователь отменяет и повторяет свои действия горячими клавишами и из меню «Правка». Стек живёт в клиентской модели и теряется при перезагрузке страницы. Обратный набор изменений применяется без запуска хуков, сервер сверяет «было/стало», и при конфликте отмена отклоняется с понятным сообщением.

**Blocked by:** 08 (Таблица свойств), 10 (Главное меню, вкладки и реестры)

**Status:** ready-for-agent

- [ ] Каждый успешный набор изменений попадает в стек отмены; новый набор очищает стек повторов
- [ ] Отмена строит обратный набор (изменение свойства, перемещение, создание, удаление) и применяет его без вызова хуков
- [ ] Отмена удаления пересоздаёт объект с тем же идентификатором, значениями и положением из снимка
- [ ] Если данные изменились (другое окно) и сервер отказал по «было/стало», стек не меняется, пользователь видит сообщение
- [ ] Пункты «Правка → Отменить / Повторить» и горячие клавиши зарегистрированы через реестр меню; недоступные пункты отключены
- [ ] Тесты `DataController` на поддельном API: отмена, повтор, отмена удаления, конфликт, очистка стека повторов; тесты UI для меню и клавиш проходят
- [ ] Запись в `CHANGELOG.md` клиента
