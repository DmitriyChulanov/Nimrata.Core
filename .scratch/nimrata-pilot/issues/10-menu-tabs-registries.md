# 10: Главное меню, вкладки и реестры

**What to build:** Универсальные главное меню и контейнер вкладок в центральной области. Модули регистрируют виды вкладок и пункты меню из TypeScript через реестры платформы; пункты могут быть доступны только определённой роли. Открытые вкладки и ширина панелей запоминаются между сессиями.

**Blocked by:** 07 (Раскладка и дерево)

**Status:** resolved

- [ ] Реестр видов вкладок: идентификатор, заголовок, компонент, разрешена ли одна копия или несколько
- [ ] Реестр пунктов меню: путь («Вид → Журнал»), обработчик, необязательное условие по роли пользователя
- [ ] Главное меню строится из реестра; пункты, недоступные роли, не показываются
- [ ] Контейнер вкладок: открытие из меню, переключение, закрытие; повторное открытие вида с одной копией переключает на существующую вкладку
- [ ] Раскладка (открытые вкладки, активная вкладка, ширины панелей) сохраняется в `localStorage` отдельно для каждого пользователя; недоступное или повреждённое хранилище не ломает приложение
- [ ] Тестовая регистрация вкладки и пункта меню в платформе доказывает, что механизм работает без модулей
- [ ] Тесты UI проходят: меню, роли, открытие, закрытие, единственная копия, восстановление раскладки, недоступное хранилище
- [ ] Запись в `CHANGELOG.md` клиента

## Answer

Реализовано на ветке `integration/nimrata-pilot` (тикет 10), код-ревью пройдено, замечания исправлены. Серверные интеграционные тесты (Testcontainers) не выполнялись из-за недоступного Docker — прогнать `DOCKER_API_VERSION=1.43 dotnet test Nimrata.Core.slnx` при рабочем Docker.
