# 05: Объекты и наборы изменений на сервере

**What to build:** Серверный контракт хранения: клиент загружает все объекты своего пользователя и отправляет набор изменений (создание, изменение свойства или перемещение, удаление). Сервер применяет набор атомарно, проверяет его по метаданным типов и записывает в журнал. Проверяется целиком через HTTP API.

**Blocked by:** 04 (Манифест и типы)

**Status:** ready-for-agent

- [ ] Миграции: таблица объектов (идентификатор от клиента, тип, родитель, владелец, порядок, значения свойств в `jsonb`), таблицы журнала (набор изменений и его записи «было/стало» и снимки)
- [ ] Эндпоинт загрузки возвращает все объекты текущего пользователя и только их
- [ ] Эндпоинт набора изменений применяет все операции в одной транзакции: либо все, либо ни одной
- [ ] Отказ набора: чужой или несуществующий объект; значения «было» не совпали с текущими; значение не подходит виду свойства или перечислению; тип неизвестен или абстрактен; родитель отсутствует или недопустим для типа; идентификатор уже занят
- [ ] Удаление записывает в журнал полный снимок объекта; создание и удаление поддерево обрабатывается явно (набор перечисляет все удаляемые объекты)
- [ ] Журнал только дописывается: в приложении нет кода, который его правит или удаляет
- [ ] Ответ при отказе содержит причину, пригодную для показа пользователю
- [ ] Интеграционные тесты HTTP API на все перечисленные случаи проходят
- [ ] Запись в `CHANGELOG.md` сервера
