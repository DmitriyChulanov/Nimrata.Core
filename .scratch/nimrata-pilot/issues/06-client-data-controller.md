# 06: Клиентская модель данных

**What to build:** Ядро клиента: `DataController`, который после входа загружает типы и все объекты пользователя в память, даёт синхронное чтение дерева и применяет изменения через набор изменений с отправкой на сервер. При отказе локальные изменения откатываются и пользователь видит причину; при расхождении данных с сервером предлагается перезагрузить данные.

**Blocked by:** 05 (Объекты и наборы изменений на сервере)

**Status:** ready-for-agent

- [ ] Загрузка типов и объектов; чтение объектов по идентификатору, потомков родителя, вычисление порядка среди соседей
- [ ] Создание, изменение свойства, перемещение и удаление выполняются через набор изменений; одно действие пользователя — один набор; идентификаторы новых объектов — клиентские UUIDv7
- [ ] Набор отправляется на сервер; при успехе локальная модель остаётся, при отказе откатывается, причина доступна подписчикам
- [ ] При отказе из-за расхождения «было» контроллер выставляет состояние «нужна перезагрузка»; перезагрузка заменяет модель данными с сервера
- [ ] Подписка на изменения модели для UI
- [ ] Тесты на поддельном API-клиенте в памяти (шов `DataController`): успех, отказ, откат, расхождение, перезагрузка
- [ ] Запись в `CHANGELOG.md` клиента
