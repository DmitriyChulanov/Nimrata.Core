# 07: Раскладка и дерево

**What to build:** Основной экран приложения с тремя панелями (дерево слева, таблица свойств справа, область вкладок по центру) с изменяемой шириной и универсальный компонент «дерево». Дерево строится по метаданным типов: иконки, сортировка, раскрытие и сворачивание. Контекстное меню даёт «Создать» (допустимые дочерние типы) и «Удалить». Пользователь видит и меняет свою структуру объектов.

**Blocked by:** 06 (Клиентская модель данных)

**Status:** ready-for-agent

- [ ] Три панели; ширина панелей меняется перетаскиванием границ; выделенный в дереве объект доступен остальным панелям
- [ ] Дерево в `platform/` не знает о Трекере: берёт типы и объекты из `DataController`
- [ ] Узлы сортируются по порядку, затем по названию; у типа есть иконка; типы с `hiddenInTree` в дереве не показываются
- [ ] Раскрытие и сворачивание узлов; отрисовка больших деревьев не тормозит (виртуализация)
- [ ] Контекстное меню узла: «Создать» (только допустимые дочерние неабстрактные типы) и «Удалить» (с подтверждением, удаляет и потомков); пункты работают через наборы изменений
- [ ] Тесты UI (Testing Library) проходят: отрисовка, сортировка, раскрытие, меню, создание и удаление
- [ ] Запись в `CHANGELOG.md` клиента
