# 15: Ссылочные свойства

**What to build:** Редактор свойства «ссылка на объект»: пользователь выбирает объект из дерева в диалоге, а потом может одним действием перейти к связанному объекту в основном дереве.

**Blocked by:** 07 (Раскладка и дерево), 08 (Таблица свойств)

**Status:** resolved

- [ ] Редактор ссылки в таблице свойств открывает диалог с деревом, где можно выбрать любой доступный объект пользователя; допустимые типы цели ограничиваются описанием свойства, если оно задано
- [ ] Значение показывается названием объекта; ссылка на удалённый объект показывается как недоступная
- [ ] Из таблицы свойств можно перейти к объекту по ссылке: узел выделяется в основном дереве, родители раскрываются
- [ ] Выбор значения применяется набором изменений
- [ ] Тесты UI проходят: выбор, ограничение по типу, переход, удалённая цель
- [ ] Запись в `CHANGELOG.md` клиента

## Answer

Реализовано на ветке `integration/nimrata-pilot` (тикет 15), код-ревью пройдено, замечания исправлены. Серверные интеграционные тесты (Testcontainers) не выполнялись из-за недоступного Docker — прогнать `DOCKER_API_VERSION=1.43 dotnet test Nimrata.Core.slnx` при рабочем Docker.
