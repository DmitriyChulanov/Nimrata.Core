# 11: Журнал

**What to build:** Пользователь открывает из меню вкладку «Журнал» и видит записи об изменениях выбранного объекта (когда, кто, свойство или операция, было, стало), а переключателем может увидеть все свои изменения. Журнал только для просмотра.

**Blocked by:** 05 (Объекты и наборы изменений на сервере), 10 (Главное меню, вкладки и реестры)

**Status:** ready-for-agent

- [ ] Эндпоинты чтения журнала: по объекту и «все мои изменения» с постраничной выдачей; только свои записи
- [ ] Записи читаются в порядке от новых к старым; создание, перенос и удаление представлены понятными строками
- [ ] Вкладка «Журнал» зарегистрирована в реестре, пункт «Вид → Журнал» открывает её
- [ ] Вкладка следит за выделением в дереве; переключатель «все мои изменения» показывает общий список
- [ ] Из вкладки ничего нельзя откатить или изменить
- [ ] Интеграционные тесты HTTP API (по объекту, все изменения, чужие записи недоступны) и тесты UI проходят
- [ ] Запись в `CHANGELOG.md` сервера и клиента
