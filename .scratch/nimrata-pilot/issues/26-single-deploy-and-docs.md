# 26: Единый деплой и документация

**What to build:** Приложение запускается как одно целое: сервер раздаёт собранный клиент, а `docker compose` поднимает приложение вместе с Postgres и Mailpit. Документация описывает запуск, настройки и архитектурные правила платформы.

**Blocked by:** 03 (Вход и первый администратор)

**Status:** resolved

- [ ] Сборка клиента включается в публикацию сервера; сервер отдаёт статические файлы и переключает неизвестные маршруты на клиентское приложение, не ломая маршруты API
- [ ] `Dockerfile` собирает приложение целиком; `docker compose` поднимает приложение, Postgres и Mailpit одной командой
- [ ] В документации перечислены настройки (строка подключения, SMTP, первый администратор, секрет JWT) и способ их задать для разработки и развёртывания
- [ ] `CLAUDE.md` обновлён: структура (`platform/`, `modules/`), команды запуска, правило про прокси API, ссылка на ADR 0001 и на словарь

- [ ] Запуск `docker compose up` на чистом окружении приводит к рабочему экрану входа
