# 09: Перенос перетаскиванием

**What to build:** Пользователь переносит узлы дерева мышью, меняя родителя и порядок среди соседей. Платформа не даёт сделать недопустимый перенос.

**Blocked by:** 07 (Раскладка и дерево)

**Status:** resolved

- [ ] Перетаскивание узла на другой узел делает его потомком; перетаскивание между соседями меняет порядок
- [ ] Недопустимые цели (тип не разрешён родителем, перенос в собственного потомка, в самого себя) подсвечиваются как недоступные и не принимают drop
- [ ] Перенос выполняется набором изменений; при отказе сервера дерево возвращается в исходное состояние с сообщением
- [ ] Перенос работает и с клавиатуры там, где это уместно (доступность не хуже базового уровня)
- [ ] Тесты UI проходят: допустимый перенос, недопустимый, смена порядка, отказ
- [ ] Запись в `CHANGELOG.md` клиента

## Answer

Реализовано на ветке `integration/nimrata-pilot` (тикет 09), код-ревью пройдено, замечания исправлены. Серверные интеграционные тесты (Testcontainers) не выполнялись из-за недоступного Docker — прогнать `DOCKER_API_VERSION=1.43 dotnet test Nimrata.Core.slnx` при рабочем Docker.
