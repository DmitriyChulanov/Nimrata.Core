# 24: Трекер: Уведомления

**What to build:** Пока вкладка приложения открыта, пользователь получает системное уведомление браузера в назначенное время задачи (с учётом «уведомить за N минут»). Задачи без времени уведомлений не создают.

**Blocked by:** 20 (Трекер: Задачи)

**Status:** resolved

- [ ] Клиентский сервис раз в минуту берёт задачи сегодняшнего дня; для каждой с заданным временем вычисляет момент уведомления как «время минус N минут»
- [ ] Уведомление показывается через Notification API один раз для задачи в день; заголовок «HH:mm», тело — название задачи
- [ ] Завершённые задачи не уведомляют
- [ ] Разрешение на уведомления запрашивается один раз по действию пользователя и не повторяется при отказе; приложение работает без разрешения
- [ ] Время сервиса можно подменить в тестах (расчёт не зависит от реального времени)
- [ ] Тесты логики расчёта (без времени, с «за N минут», завершённая, уже показанное, смена суток) и UI (запрос разрешения) проходят
- [ ] Запись в `CHANGELOG.md` клиента

## Answer

Реализовано на ветке `integration/nimrata-pilot` (тикет 24), код-ревью пройдено, замечания исправлены. Серверные интеграционные тесты (Testcontainers) не выполнялись из-за недоступного Docker — прогнать `DOCKER_API_VERSION=1.43 dotnet test Nimrata.Core.slnx` при рабочем Docker.
