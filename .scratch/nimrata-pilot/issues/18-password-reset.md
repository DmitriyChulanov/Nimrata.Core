# 18: Сброс пароля по e-mail

**What to build:** Пользователь сам сбрасывает забытый пароль по ссылке из письма; администратор может отправить такую ссылку пользователю из админки. Почта настраивается в конфигурации, в разработке письма перехватывает Mailpit из `docker compose`.

**Blocked by:** 03 (Вход и первый администратор), 17 (Админка пользователей)

**Status:** resolved

- [ ] Эндпоинт запроса сброса принимает e-mail и всегда отвечает одинаково, не раскрывая, есть ли такой пользователь
- [ ] Одноразовая ссылка с ограниченным сроком жизни приходит письмом; эндпоинт подтверждения принимает новый пароль (минимум 8 символов) и отзывает старые refresh-токены
- [ ] SMTP-параметры берутся из настроек; в `docker compose` добавлен Mailpit, адрес его интерфейса описан в документации
- [ ] Клиент: ссылка «Забыли пароль?» на экране входа, формы запроса и установки нового пароля
- [ ] В админке кнопка «Отправить ссылку на смену пароля» отправляет то же письмо выбранному пользователю
- [ ] Интеграционные тесты HTTP API с поддельным почтовым сервисом (запрос, истёкшая ссылка, повторное использование ссылки, неизвестный e-mail) и тесты UI проходят
- [ ] Запись в `CHANGELOG.md` сервера и клиента

## Answer

Реализовано на ветке `integration/nimrata-pilot` (тикет 18), код-ревью пройдено, замечания исправлены. Серверные интеграционные тесты (Testcontainers) не выполнялись из-за недоступного Docker — прогнать `DOCKER_API_VERSION=1.43 dotnet test Nimrata.Core.slnx` при рабочем Docker.
