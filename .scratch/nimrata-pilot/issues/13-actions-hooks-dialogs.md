# 13: Действия, хуки и диалог параметров

**What to build:** Механизм бизнес-логики модулей на клиенте: хуки до и после операций (создание, изменение свойства, перемещение, удаление) с возможностью отменить операцию, реестр обработчиков действий по идентификаторам из манифеста и диалог ввода параметров, который платформа рисует по описанию. Действия видны кнопками в таблице свойств и пунктами контекстного меню в соответствии с `placements`.

**Blocked by:** 06 (Клиентская модель данных), 07 (Раскладка и дерево), 08 (Таблица свойств)

**Status:** ready-for-agent

- [ ] Реестр хуков: регистрация по типу и операции; хук «до» может отменить операцию с сообщением, хук «после» может дополнить тот же набор изменений
- [ ] Операции внутри хуков (создание узлов, перенос, правка) входят в тот же набор изменений, что и исходное действие пользователя
- [ ] Реестр обработчиков действий: привязка по идентификатору типа и действия; действие без обработчика не показывается
- [ ] Параметры действия (восемь видов свойств) собираются диалогом, который строится по описанию; обязательные параметры проверяются
- [ ] Действие всегда имеет объект-цель; кнопки в таблице свойств и пункты контекстного меню показываются по `placements` (`propertyGrid`, `contextMenu`)
- [ ] Возможность отключить запуск хуков для внутренних операций (нужна для повторов и Undo)
- [ ] Тесты `DataController` (отмена хуком, дополнение набора, отключение хуков) и тесты UI (кнопки, меню, диалог, обязательные параметры) проходят
- [ ] Запись в `CHANGELOG.md` клиента
