# 08: Таблица свойств

**What to build:** Универсальная таблица свойств выбранного объекта: свойства сгруппированы по категориям, правка на месте, редакторы по виду свойства. В этом тикете поддержаны строка, многострочный текст, целое число, логическое, дата, время и перечисление. Каждая правка — набор изменений.

**Blocked by:** 07 (Раскладка и дерево)

**Status:** ready-for-agent

- [ ] Таблица строится по описанию типа выбранного объекта: категории, порядок, названия
- [ ] Редакторы для строки, многострочного текста, целого числа, логического, даты (`YYYY-MM-DD`), времени (`HH:mm`) и перечисления; недопустимый ввод не отправляется
- [ ] Свойства «только чтение» недоступны для правки
- [ ] Значения по умолчанию из определения свойства подставляются при создании объекта
- [ ] Правка применяется как набор изменений; при отказе значение откатывается и показывается причина
- [ ] Ссылочные свойства показываются как текст «только чтение» (редактор — в тикете 15)
- [ ] Тесты UI проходят: отрисовка, правка каждого вида, только чтение, отказ
- [ ] Запись в `CHANGELOG.md` клиента
