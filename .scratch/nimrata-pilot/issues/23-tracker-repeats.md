# 23: Трекер: Повторы

**What to build:** Пользователь делает задачу повторяющейся (каждый будний день, каждую неделю, каждый месяц), и расписание наполняется реальными задачами на горизонт до конца следующего месяца. Повторы достраиваются при каждом входе, правки распространяются на весь набор, выключение повтора удаляет созданные повторы.

**Blocked by:** 21 (Трекер: «Завершить» и «Отложить»)

**Status:** resolved

- [ ] При включении повтора создаётся набор с общим идентификатором повтора; для каждой подходящей даты до конца следующего месяца создаётся задача в дне (узлы по требованию) с той же цепочкой категорий; дубликаты в наборе пропускаются
- [ ] «Каждый будний день» пропускает субботу и воскресенье; для задачи, лежащей в дне-выходном, включение повтора отклоняется с сообщением
- [ ] «Каждую неделю» добавляет 7 дней, «каждый месяц» добавляет месяц
- [ ] Изменение названия, комментария, внешней ссылки, приоритета, времени или порядка у любой задачи набора распространяется на остальные; такие правки идут с отключёнными хуками, чтобы избежать рекурсии
- [ ] Выключение повтора удаляет все созданные повторы набора и очищает идентификатор повтора
- [ ] При каждом входе в приложение недостающие повторы достраиваются до горизонта
- [ ] Тесты `DataController` на поддельном API (будни, неделя, месяц, выходной, синхронизация, выключение, достройка, отсутствие дублей) проходят
- [ ] Запись в `CHANGELOG.md` клиента
