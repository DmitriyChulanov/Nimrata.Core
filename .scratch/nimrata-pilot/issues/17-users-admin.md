# 17: Админка пользователей

**What to build:** Администратор открывает из меню «Администрирование → Пользователи» вкладку со списком пользователей и управляет ими: создаёт учётные записи с паролем, меняет роль, отключает и включает вход. Участник пункт меню не видит.

**Blocked by:** 03 (Вход и первый администратор), 10 (Главное меню, вкладки и реестры)

**Status:** ready-for-agent

- [ ] Эндпоинты администрирования (только роль «Администратор»): список, создание (e-mail, имя, пароль, роль), смена роли, отключение и включение; пользователей не удаляют
- [ ] Нельзя отключить или понизить последнего администратора; сервер отклоняет такую операцию с понятной причиной
- [ ] Участник получает отказ на эндпоинтах администрирования
- [ ] Вкладка «Пользователи» в реестре вкладок; пункт меню виден только администратору (условие по роли из тикета 10)
- [ ] Отключённый пользователь больше не входит и его refresh-токены перестают работать
- [ ] Интеграционные тесты HTTP API (роли, последний администратор, отключение) и тесты UI проходят
- [ ] Запись в `CHANGELOG.md` сервера и клиента
