# 05: Вкладка «Редактор расширений»

**What to build:** Пользователь открывает Редактор расширений из меню «Вид → Расширения», видит карточки доступных расширений и подключает или отключает их.

**Blocked by:** 04

**Status:** resolved

- [x] Вид вкладки с одной копией в `tabRegistry` и пункт меню «Вид → Расширения»
- [x] Карточка: название, иконка из реестра иконок, описание, переключатель «Подключено»; под переключателем текст «Данные скрываются и вернутся при повторном подключении»; диалога подтверждения нет
- [x] Только UI-кит и токены из `tokens.css`; проверены обе темы, видимый фокус и контраст AA; `npm run lint` проходит
- [x] Пустое состояние рабочей области, когда отключены все расширения
- [x] Тесты Testing Library: открытие вкладки, переключение, ошибка сервера, доступность переключателя с клавиатуры
- [x] Запись в `CHANGELOG.md` клиента

## Answer

Реализовано на ветке `integration/extensions`. 529 тестов клиента, lint и tsc проходят. Проверено вживую в обеих темах (отключение и включение без перезагрузки, пустое состояние). Не проверено: ошибка `setConnected` вживую, контраст AA инструментом. При ошибке она видна и у карточки, и в глобальном alert провайдера.
