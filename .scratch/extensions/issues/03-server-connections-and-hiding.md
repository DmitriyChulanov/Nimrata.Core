# 03: Сервер: подключения, скрытие данных, singleton

**What to build:** Сервер хранит подключения расширений по пользователям и скрывает данные отключённых расширений в объектах и журнале.

**Blocked by:** 02

**Status:** needs-triage

- [ ] Таблица подключений «пользователь × расширение × включено» с каскадным удалением по пользователю; нет записи — состояние по `defaultEnabled`
- [ ] Метаданные расширения (название, описание, иконка из реестра, `defaultEnabled`) в манифесте и в `ManifestValidator`; `GET /api/extensions` и `PUT /api/extensions/{id}/connection` (пользователь меняет только свои)
- [ ] Чтение объектов не возвращает объекты типов отключённых расширений; типы платформы видны всегда
- [ ] `ManifestValidator` запрещает вложенность типов разных расширений
- [ ] Создание, изменение, перемещение и удаление объекта отключённого расширения отклоняется с ошибкой «Расширение отключено»
- [ ] `changeset_entries.type_id`: пишется `ChangesetService`, бэкфилл в миграции с обходом триггера неизменяемости (живые — из `objects`, удалённые — из `create`/`snapshot`); `JournalService` скрывает записи отключённых расширений, неопределённый тип виден всегда
- [ ] `singleton` в манифесте на `TasksRoot`, `CurrentTasksRoot`, `CompletedTasksRoot`, `NotesRoot`, `SelectTodayMechanism`; второй объект у того же родителя и владельца отклоняется
- [ ] Тесты Testcontainers на каждый пункт, включая набор изменений, затрагивающий оба расширения
- [ ] Запись в `CHANGELOG.md` сервера
