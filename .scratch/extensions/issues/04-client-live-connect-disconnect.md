# 04: Клиент: подключение и отключение без перезагрузки страницы

**What to build:** Клиент знает состояние подключений, регистрирует и снимает расширения на лету и корректно обновляет состояние при переключении.

**Blocked by:** 03

**Status:** resolved

- [x] Клиент загружает каталог расширений и подключает только подключённые; `App` не знает о конкретных расширениях
- [x] Переключение: снятие или регистрация хуков и действий, перезагрузка данных (`load()`), очистка Undo/Redo, сброс выделения на недоступные объекты; вкладки платформы остаются
- [ ] Сброс вкладок, привязанных к недоступным объектам: не реализовано, таких вкладок нет (все вкладки платформенные)
- [x] При подключении `ensureStart` вызывается после перезагрузки данных; отказ сервера по `singleton` считается «уже есть»
- [x] Пока «Трекер задач» отключён, не работают повторы и уведомления; при подключении `ensureRepeats` достраивает пропущенное
- [x] Ссылки на скрытые объекты ведут себя как на отсутствующие («Объект по ссылке недоступен»)
- [x] `fakeApi` и существующие тесты обновлены под новые эндпоинты; тесты переключения (данные скрыты и возвращаются, Undo очищен, нет дубликатов корней)
- [x] Запись в `CHANGELOG.md` клиента

## Answer

Реализовано на ветке `integration/extensions`. 514 тестов клиента, lint и tsc проходят. Вживую (сервер + Vite + Postgres) не проверялось; поведение сервера смоделировано в `fakeApi` по контракту тикета 03.

### API для тикета 05 (всё из `@platform`)

```ts
useExtensions(): ExtensionsValue // бросает ошибку вне ExtensionsProvider
interface ExtensionsValue {
  status: 'loading' | 'ready' | 'error'; // 'error' — только сбой каталога
  error: string | null;
  extensions: ExtensionInfo[]; // {id,name,description,icon,defaultEnabled,connected}
  switchingId: string | null;
  setConnected(id: string, connected: boolean): Promise<ChangeResult>;
  reload(): Promise<void>;
}
```

`ExtensionsProvider` стоит в `App` вокруг `Main` и показывает глобальный alert только для ошибки каталога или запуска; ошибка переключения возвращается из `setConnected` и показывается у карточки Редактора расширений. Повторное переключение во время идущего отклоняется.

### Известные ограничения

- Вкладки, привязанные к объектам, не реализованы: таких вкладок нет (все вкладки сейчас платформенные), при переключении сбрасывается только выделение.
- `ExtensionsProvider` под `StrictMode` отдельно тестами не покрыт.
